# Pomodoro Timer  

A simple **Pomodoro Timer** built with **React**, **TypeScript**, **Vite**, and **shadcn/ui**. Check out [Pomodoro Timer Roadmap Project](https://roadmap.sh/projects/pomodoro-timer) for more information.

**Live Demo:** [Click here](https://pomodoro-timer-jaceylab.vercel.app/)

---

### Tech Stack  
React • TypeScript • Vite • shadcn/ui • Tailwind • Zustand • Vercel

---

### Features  
- Start/Pause/Reset pomodoro timers.
- Custom timer settings
- Auto-switch between sessions  
- Session history tracking  
- Dark/light mode
- Fireworks animation after each Focus completes

---

### Run Locally  
```bash
git clone https://github.com/naeminhye/pomodoro-timer.git
cd pomodoro-timer
npm install
npm run dev
```

Then open in [local](http://localhost:5173).
